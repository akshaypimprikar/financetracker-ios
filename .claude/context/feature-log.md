## v1.5.0 — 2026-09-29
**Features added:** Pipeline lanes and enforced merges: `scripts/check_pr_lane.py` sorts each PR into `app`, `pipeline`, `docs` or `release` from its changed paths (`scripts/pipeline_lanes.json`), and a new `review-evidence` check (`pull_request_target`, run from the base branch, reads the PR only through the API) verifies each lane's evidence: gate summary, `/review` APPROVED and `code-review:` line at the head SHA, `Motivating incident:` for pipeline changes; it fails closed at GitHub's 300-file compare cap. The `gates` job moved to `gates.yml` and runs on every PR, adding `scripts/check_citations.py` and the script unit tests. `/review` capped at two rounds with `Reviewed at <sha>` verdicts, and its judgment checks run in a fresh-context subagent. Stage order: `/pr-followup` runs `code-review:code-review` before `/review`; `/test` is a coverage-gap audit before `/gates`; `/release` back-merges through a PR. 2026-09-24 pipeline-review fixes pulled from pragma. No app-code changes.
**Key files changed:** `scripts/check_pr_lane.py`, `scripts/check_review_evidence.py`, `scripts/check_citations.py`, `scripts/tests/` (all new), `scripts/pipeline_lanes.json` (new), `.github/workflows/gates.yml` + `review-evidence.yml` (new), `.github/workflows/pr-checks.yml`, `.claude/hooks/guard_protected_paths.py`, `scripts/check_gate_integrity.py`, `.claude/skills/{gates,review,pr-followup,test,spec,plan,feature,bugfix,release}/SKILL.md`, `AGENTS.md`
**Key architectural decisions:** Merge evidence moved from agent instructions to CI checks that a PR cannot edit (`review-evidence` runs from the base branch). Lanes come from changed paths, so a mixed app+pipeline PR owes every touched lane's evidence. `gates` and `review-evidence` become required checks on `develop` and `main` after this release; `Concurrency Advisory` stays non-required while its TSan crash (#136) is open.

## v1.4.0 — 2026-09-24
**Features added:** `/gates` and `/review` verify instead of trust — `/review` re-runs the deterministic gates at the PR HEAD SHA and rejects a mismatched `Gates run at <sha>` line; `/gates` gains a clean-tree pre-step, a widened Gate 0 trigger, Gates 1-2 that fail on zero executed tests, a wider Gate 9 money-`Double` heuristic plus `ImportHashGoldenTests`, and Gate 13 (gate integrity). `PreToolUse` guard hook (`.claude/hooks/guard_protected_paths.py`) blocking gate-definition edits on `feature/*`, hardened from pragma #77 (self-test 52 → 174 checks). Advisory Gate 12 visual verification spike. AGENTS.md + Agent Skills migration. Fixes: Xcode 27 / Swift 6.4 build break (`TransactionImportWriting`/`CategorySuggesting` made `nonisolated`, gated `#if compiler(>=6.4)`); `/test` and `/release` pre-flight no longer hide `xcodebuild`'s exit status behind `xcsift`; pipeline-review alert and `/status` read the `addressed:` flag from frontmatter only.
**Key files changed:** `FinanceTracker/Repositories/Protocols/TransactionImportWriting.swift`, `FinanceTracker/Services/CategorySuggesting.swift`, `FinanceTracker/Services/FoundationModelsCategorySuggester.swift`, `FinanceTrackerTests/ImportHashGoldenTests.swift` (new), `.claude/hooks/guard_protected_paths.py`, `scripts/check_gate_integrity.py`, `.github/workflows/pr-checks.yml`, `.claude/skills/*/SKILL.md` (migrated from `.claude/commands/`), `AGENTS.md`, `.claude/context/invariants.md`
**Key architectural decisions:** Invariant #6 — a protocol that an `actor` conforms to must be declared `nonisolated` (under `#if compiler(>=6.4)`), because the project's `SWIFT_DEFAULT_ACTOR_ISOLATION = MainActor` otherwise infers `@MainActor` onto it under Swift 6.4.

## v1.2.1 — 2026-08-16
**Features added:** `/gates` Gate 10 (restored generic duplication/abstraction-bloat heuristic, originally from pragma) and Gate 11 (RED-before-GREEN commit order — `/feature` now commits the failing test and its implementation separately, `scripts/check_tdd_commit_order.py` verifies the order from git history rather than trusting agent self-report; Gate 11 specifically was also ported to the pragma template repo as a generic gate); README screenshots via a new `--seedscreenshots`/`--starttab` demo-data launch path
**Key files changed:** `.claude/commands/feature.md`, `.claude/commands/gates.md`, `.claude/commands/plan.md`, `.claude/commands/sync-workflow.md`, `.claude/commands/review.md`, `scripts/check_tdd_commit_order.py`, `.claude/settings.json`, `.claude/context/rejections.md`, `FinanceTracker/Debug/DemoDataSeeder.swift`
**Key architectural decisions:** RED and GREEN are separate, independently-committed steps per task (not squashed), specifically so git history itself is the audit trail for TDD discipline rather than an agent's narration of having followed it; `check_tdd_commit_order.py` uses `git log develop..HEAD` (double-dot) not triple-dot, since triple-dot's symmetric-difference semantics for `git log` (distinct from `git diff`) would silently include unrelated commits from an advancing base branch
